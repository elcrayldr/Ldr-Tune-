# Compilación en GitHub
1. Sube todo el contenido de esta carpeta a un repositorio (incluida `.github`).
2. En **Actions > Build VST3** pulsa **Run workflow** (o haz push).
3. Descarga `CrayLdrRealtimeTune-VST3` en **Artifacts**.
4. Copia la carpeta `CRAY LDR REALTIME TUNE.vst3` a `C:\Program Files\Common Files\VST3\` y reescanea plugins.
